# Портал администрации SCP:SL · версия 2.1

Закрытый портал администрации с личными кабинетами в стилистике Зоны 82-EX.

## Уже реализовано

- личное кадровое досье каждого администратора;
- должность, системная роль, уровень допуска и статус подтверждения;
- счётчики устных предупреждений и строгих выговоров;
- журнал дисциплинарных взысканий с причиной, автором и датой;
- привязка Discord через OAuth2;
- привязка Steam через Steam OpenID;
- статистика проведённых ивентов и суммарного времени;
- таблица истории ивентов внизу личного кабинета;
- общий реестр ивентов и рейтинг организаторов;
- автоматическое начисление баллов через API игрового сервера;
- Discord-бот с обновляемыми карточками ивентов, журналом и slash-командами;
- личные и групповые чаты через Socket.IO;
- журнал действий руководства;
- самостоятельная регистрация с необязательным кодом приглашения;
- миграция старой базы без удаления существующих сотрудников.

## Баллы за ивенты

| Продолжительность | Баллы |
|---|---:|
| Короче 10 минут | 0 |
| 10:00–29:59 | 2 |
| 30:00–60:00 включительно | 3 |
| Более 60 минут | 5 |

Баллы выдаются только после вызова API завершения ивента.

## Discord-бот

Бот запускается вместе с порталом и не требует отдельного Railway-сервиса. Он обновляет карточку ивента после завершения или отмены и предоставляет команды:

```text
/profile
/warnings
/events
/event-top
/event-active
/link
```

Пошаговая настройка находится в `docs/DISCORD-SETUP-RU.md`.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
cp .env.example .env
npm install
npm start
```

Откройте `http://localhost:3000`.

Стандартный владелец до изменения `.env`:

- логин: `administrator`
- пароль: `ChangeMe_123!`

## Файлы

- `server.js` — API, OAuth, SQLite, Discord-бот и Socket.IO;
- `public/index.html` — интерфейс портала;
- `public/styles.css` — оформление в стиле закрытого досье;
- `public/app.js` — клиентская логика;
- `docs/RAILWAY-DEPLOY-RU.md` — развёртывание;
- `docs/DISCORD-SETUP-RU.md` — создание приложения и бота;
- `docs/SCP-SL-INTEGRATION.md` — контракт API для EXILED-плагина.

## Хранение данных

Используется встроенный SQLite-модуль Node.js 22. На Railway обязательно подключите Volume и задайте:

```env
DATA_DIR=/app/data
```

Путь монтирования Volume:

```text
/app/data
```

В этой папке сохраняются база `foundation.db` и загруженные аватары.
